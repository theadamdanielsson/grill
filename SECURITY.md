# Security

Grill can edit notes and, on Grill Cloud, takes payments. If you find a way to make it
do something a user did not agree to, I want to hear about it before anyone else does.

## Reporting a problem

Please do not open a public issue or discussion. Use
[Report a vulnerability](https://github.com/theadamdanielsson/grill/security/advisories/new)
on this repository, or email inquiries@onbridger.com.

Say what you did, what happened, and which version of Grill and Obsidian you were on. I
will answer within a few days and tell you when a fix is out.

## What counts

- A note changed, created or read outside what the permission level allows.
- Note content or model output that runs code, loads remote content or leaks keys.
- Anything that exposes an API key or a Grill Cloud key.
- Grill Cloud credits spent, granted or billed wrongly.

## Versions

Only the latest release gets fixes.
