# Code of conduct

This covers issues, pull requests and discussions here.

- Be decent to each other. Disagree with the idea and leave the person alone.
- No harassment, no insults, no posting anyone's private information.
- No spam, no ads.
- Stay on Grill. This is a small project and I read everything myself.

I will remove what breaks this, and block repeat offenders. To report something,
email inquiries@onbridger.com.
